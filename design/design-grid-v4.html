Senior and low vision launcher, design grid v4, final

Working name: TBD  |  1px = 1dp, frames 412dp wide  |  This file is the measurement authority
v4 build requirements not visible in frames: full TalkBack labeling and focus order on every screen; messages persisted in a local on-device store; all text in sp, tested at 200 percent font scale; RTL mirroring and Arabic, Spanish, Chinese locales with Noto fallbacks (Young Serif is Latin-only, clock digits only); system Remove-animations respected; tremor debounce and enlarged touch slop everywhere; weather is opt-in and off by default.

Color

paper F4EEE1 card FDFAF2 ink 2A2723 navy 2E4A66 cream F6EFDF lamp F4E4B9 green 35704E red AF3B2B
  • red: emergency only. green: well and done only
  • lamp: attention, caution, and undo. The one
  • non-red warning voice, always with icon + words

Type

  • Young Serif (OFL, confirmed): clock only
  • Atkinson Hyperlegible Next: everything else,
  • titles at 800 weight in navy
  • Atkinson Hyperlegible Mono: time + status
  • clock 94 / titles 34 / labels 25-28 / body 24

Depth + themes

  • default: soft-shadow keys, no borders
  • Strong outlines theme: 3dp ink borders,
  • shadows off (WCAG 1.4.11 edge contrast)
  • Light default, Dark by choice
  • one separation device per element, always

Touch + state

  • tiles 128dp, keys 88dp floor, gaps 12-14dp
  • no swipe, drag, long press, double tap, pinch
  • watched states: ringer, battery, network,
  • airplane, DND, storage, notification access
  • attention queue: many items, one lamp
